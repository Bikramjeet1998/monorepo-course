✅ Q1. What is a module?

Your answer:

module is a js file where is the its related stuff

✅ Correct!

A more professional definition:

A module is a JavaScript file that contains related code and can be imported and reused in other files.

Example
math.js

Contains

export function add() {}
export function sub() {}

This whole file is a module.

✅ Q4. Difference between Named Export and Default Export

Your answer:

some time export by function name {}

some time default export

Good!

Let's make it crystal clear.

Named Export
// math.js

export function add() {}

export function sub() {}

Import

import { add, sub } from "./math.js";

Notice the {}.

Default Export
export default function Button() {}

Import

import Button from "./Button.js";

No {}.

Easy Trick
Export Type	Import Syntax
export	import { add } from "./math.js"
export default	import Button from "./Button.js"
