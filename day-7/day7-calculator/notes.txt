🧩 Debugging Challenge

You answered:

because filename is incorrect Math.js should be math.js

⭐⭐⭐⭐⭐

Excellent!

This is one of the most common bugs developers face.

Suppose your file is:

math.js

But you write:

import { add } from "./Math.js";
On Windows

It may work because Windows is often case-insensitive.

On Linux or macOS

It will fail because they are usually case-sensitive.

That's why professional developers always match the file name exactly.
