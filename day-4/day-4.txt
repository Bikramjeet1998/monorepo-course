✅ Q3. What are Scripts?

Your answer:

scripts are like commands that we use to run project/file or build etc.

✅ Very Good!

Professional definition:

Scripts are custom commands that we define inside package.json.

Examples:

"scripts": {
   "dev":"vite",
   "build":"vite build",
   "hello":"node hello.js"
}

Then we can run

npm run hello
npm run build
npm run dev

Very good understanding.
